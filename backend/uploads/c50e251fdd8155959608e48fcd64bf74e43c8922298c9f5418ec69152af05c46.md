## 项目经验
**一、多源竞品监控与异常告警 Agent（独立开发）**
**项目描述：**
一个 LLM 驱动的**多源竞品监控与异常告警系统**，自动巡检 **GitHub Release**、**电商商品价格**、**App Store 评分**三类数据源，完成「采集 → 基线对比 → 异常判定 → 告警推送 → 结构化报告」的全链路闭环。核心设计哲学：**LLM 只做决策与编排，所有精确计算由确定性代码执行**，杜绝大模型幻觉算错价格的零容忍事故。
**主要工作：**

1. 基于 **LangGraph** 搭建「采集分析 → 路由 → 人工确认 → 通知 → 报告」编排图；通过 **Function Calling** 接入 **17 个确定性工具**；LLM 在 **ReAct 循环**中自主完成采集与告警创建；数值比较统一收敛到唯一的 **compare_metrics** 代码入口。
2. 设计**策略模式采集器**架构，新增数据源仅需继承基类并注册一行；统一 **{"product_id", "metric", "value", "collected_at"}** 输出格式；已接入 GitHub / 电商价格 / App Store 共 **4 类数据源**；网络请求统一 **tenacity 指数退避重试**。
3. 实现基于 **interrupt()** 的 **Human-in-the-Loop 门控**：critical 告警**确定性暂停**等待人工批准、warning/info 直通；配合 **SqliteSaver checkpoint（WAL 模式）持久化**，进程崩溃后可从断点 resume 继续，不丢上下文。
4. 实现**双通道异常检测**：阈值比较抓「幅度」异常、**Isolation Forest** 抓「形状」异常；告警按 product+type **24h 自动去重**；重复出现的 warning **自动升级为 critical**，避免告警轰炸。
5. 实现**飞书/钉钉 Webhook 推送**（HMAC 加签）、**Jinja2** 渲染 Markdown/HTML 结构化报告；并通过 **eval_runs** 表自动统计每次运行的**成功率与延迟**，形成客观自我评估闭环；配套 **pytest 64 项测试**与 **GitHub Actions CI**，支持 **APScheduler 定时巡检**与产品注册表管理。

**二、DocRAG · 垂直领域智能文档问答系统（独立开发）**
**项目描述：**
一套完整的 **RAG 工程实践**：上传 PDF/DOCX/PPT 等 **8 种格式**文档，经「语义切分 → 混合检索 → Query 增强 → Rerank 精排」后，由 LLM **流式生成带引用来源**的回答。前后端分离：**FastAPI + LangChain** 后端、**Vue 3 + Vite** 前端，向量库采用 **Milvus（Docker Compose）**，LLM/Embedding/Rerank 均接入 OpenAI 兼容云 API。
**主要工作：**

1. 实现**向量 + BM25 混合检索**双路召回（**rank_bm25** + **jieba** 中文分词）；多查询结果合并去重；互补解决「语义相似但无关键词」与「关键词精确但语义跑偏」问题，专有名词与代码片段不漏检。
2. 实现 **Query 改写补指代 + HYDE 假想答案**并行增强扩大召回，失败自动降级原 query；**Rerank 精排**（**bge-reranker-v2-m3** 交叉编码）坚持用**原始 query**，贴合用户本意。
3. 设计**双分块策略**：短文档按句子 embedding 相似度语义断块（均值-1.5σ 阈值、碎块合并）；长文档固定切分；**chunk_type** 标记共存，兼顾精度与成本。
4. 实现 **SSE 逐字流式问答**（打字机渲染 + 思考动画 + 引用来源卡片），检索置于 **asyncio.to_thread** 防阻塞事件循环；**SQLite** 持久化对话记忆（存 50 轮取 6 轮），刷新页面自动续聊。
5. 搭建 **RAGAS 离线评估**体系：自动生成中文测试集 + faithfulness/answer_relevancy/context_precision/context_recall **四项指标量化**，产出 Markdown/JSON 报告；实测 **忠实度 0.915、上下文召回 0.950、上下文精度 0.830**。
